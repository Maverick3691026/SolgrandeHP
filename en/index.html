This website presents worldbuilding and reference materials for the original fantasy work Old Unknown.

Some illustrations and setting materials may contain combat, bloodshed, themes of life and death, or mild skin exposure based on the traits of a particular race.

Long Term Structure

An Ever-Expanding World

Designed to grow beyond one thousand pages, this site uses fixed hierarchies and naming rules for each category. New nations, people, systems of magic, and historical records can be added without disrupting the existing design.

  • Reference materials are organized in category directories
  • Detail pages are added beneath each category’s entries directory
  • Shared CSS keeps presentation consistent
  • JavaScript is limited to interaction support
